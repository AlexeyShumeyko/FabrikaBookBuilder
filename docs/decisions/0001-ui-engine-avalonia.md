# 1. Интерфейс переносим на Avalonia, ядро остаётся на C#

- **Статус:** принято
- **Дата:** 2026-10-03

## Контекст

Программа написана на WPF. WPF живёт только на Windows, а движок не умеет читать JPEG
с уменьшением: чтобы показать превью в 500 пикселей, он читает все 24 мегапикселя целиком.
Это самая дорогая операция в продукте — на 20 книг по 9 фотографий уходит около 42 секунд
и 2,3 ГБ памяти.

Дальше проверяли, можно ли обойтись без смены движка: системные API Windows умеют то же
самое, но это прямой вызов Win32, который придётся писать заново для каждой платформы и
выбрасывать при переезде.

## Решение

Интерфейс переносим на Avalonia. Предметная область, правила и сценарии остаются обычным
C# без изменений — меняется только оболочка.

## Последствия

**Хорошо**

- Один движок для Windows и macOS вместо двух оболочек с общей логикой.
- Avalonia декодирует JPEG с уменьшением, поэтому превью становится дешёвым без
  костылей и на всех платформах сразу.
- Производительность уезжает вместе с ядром: меняется адаптер, а не логика.

**Плохо**

- Интерфейс придётся переписать, а не «перенести». Это несколько месяцев работы.
- Часть возможностей WPF в Avalonia нет, и внешний вид может отличаться. Правило для
  этого — решение [0004](0004-avalonia-may-look-different.md).
- WPF-сборку нужно поддерживать до тех пор, пока Avalonia не пройдёт приёмку.

## Альтернативы, которые отвергли

| Вариант | Почему нет |
|---|---|
| Остаться на WPF | Нет macOS, превью остаётся дорогим, поддержка Windows закончится вместе с .NET |
| Tauri | Нужен веб-разработчик, а проект на C#: ради переезда пришлось бы выбрасывать код |
| Flutter, Electron | То же самое, плюс своя среда выполнения вместо .NET |
| Чистый вызов Win32 для превью | Работает, но код намертво привязан к Windows и умирает при переезде |

## Проверка перед принятием

Пробное приложение на Avalonia с замерами: время старта, память и — главное — скорость
создания превью на тех же фотографиях. Если превью не станет заметно дешевле, перенос
останавливается и вопрос решается заново.
