# 6. Текст релиза — текст для пользователя

- Статус: принято
- Дата: 2026-10-03

## Контекст

В версии 1.1.0 окно обновления показывало пользователю адрес репозитория, учётную
запись автора и ссылки на изменения. Причина: пайплайн дописывал к заметкам
автоматический блок GitHub (`generate_release_notes: true`), а окно отображало тело
релиза целиком.

## Решение

1. Текст релиза пишется вручную в `docs/release-notes/v<версия>.md` и целиком
   становится описанием релиза. Автоматические блоки не добавляются:
   `generate_release_notes: false`.
2. В тексте релиза не допускаются ссылки, упоминания и адреса репозитория.
3. Markdown ограничен тем, что окно обновления умеет отображать: заголовки, выделения,
   списки, моноширинный текст. Таблицы, изображения, цитаты и ссылки не используются.
4. Требования проверяются автоматически: `scripts\check-release-notes.ps1` выполняется
   в CI на каждом слиянии и перед выпуском.

## Последствия

- Страница релиза на GitHub не содержит списка коммитов со ссылками. Состав изменений
   доступен в истории коммитов.
- Ошибка в формате заметок обнаруживается до слияния, а не после публикации.
- Проверка на данных релиза 1.1.0 подтверждает, что окно удаляет автоматический блок
   (42 строки из 70 остаются, ссылок и упоминаний нет).
