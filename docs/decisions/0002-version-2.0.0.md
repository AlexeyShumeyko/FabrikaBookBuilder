# 2. Следующая версия — 2.0.0

- Статус: принято
- Дата: 2026-10-03
- Связано с: [0001](0001-ui-engine-avalonia.md)

## Контекст

Перенос интерфейса на другой движок заменяет все видимые пользователю поверхности:
разметку экранов, диалоги, списки и загрузку изображений.

Совместимость при этом сохраняется:

| Контракт | Изменение |
|---|---|
| Формат файла проекта | нет |
| Имена файлов при выгрузке (`001-00.jpg`) | нет |
| Путь данных `%LOCALAPPDATA%\PhotoBookRenamer` | нет |
| Набор сценариев и их результат | нет |

По формальным правилам SemVer это изменение на 1.x.

## Решение

Выпуск с переносом интерфейса получает номер **2.0.0**.

## Обоснование

- SemVersion описывает совместимость API для потребителей библиотеки. Потребитель
  этого приложения — конечный пользователь, для него изменён весь интерфейс.
- Линия выпусков разделяется: 1.x — оболочка на WPF, 2.x — оболочка на Avalonia.
- Формат проекта и имена файлов не меняются, поэтому переход для пользователя
  сводится к замене программы.

## Правила

- Номер версии поднимается один раз, в момент выпуска; до этого в проекте остаётся
  текущая версия.
- Версия записывается в `PhotoBookRenamer.csproj` и в тег релиза `v<версия>`.
- Сборка релиза отказывается собирать версию, для которой уже существует тег.
