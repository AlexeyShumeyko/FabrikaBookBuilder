# 5. Тесты обязательны

- Статус: принято
- Дата: 2026-10-03

## Контекст

Автоматических тестов нет. Проверка выполняется сценариями из `scripts/`, которые
требуют запущенной программы и нажатий. Такой способ ловит отказ, но не ловит
изменение результата: переименование файла при выгрузке останется незамеченным, пока
не появится папка с неверными именами.

Волны 1 и 2 переносят и переписывают работающий код. Без тестов, фиксирующих текущее
поведение, нельзя отличить сохранённое поведение от случайно изменённого.

## Решение

1. Тест на текущее поведение пишется **до** переноса кода. Перенесённый кусок
   переписывается, тест остаётся.
2. Фреймворк — xUnit. Платные библиотеки для проверок не используются.
3. Покрытие измеряется и не уменьшается.
4. Тесты обязательны для слияния.

## Структура

| Проект | Что покрывает |
|---|---|
| `PhotoBook.Core.Tests` | имена файлов, раскладка разворотов, проверка папок, план выгрузки |
| `PhotoBook.Application.Tests` | сценарии с подменой портов |
| `PhotoBook.Infrastructure.Tests` | чтение и запись проектов, копирование файлов на временных каталогах |

## Границы применимости

Автоматизированной проверки интерфейса нет: `Avalonia.Headless` в проекте не подключён,
экраны проверяются сценариями `scripts/` и сравнением снимков. Автоматические тесты
покрывают правила, сценарии и контракты — 125 тестов в одном проекте
`tests/PhotoBook.Application.Tests`; дробить его по слоям не потребовалось.

## Проверки перед слиянием

| Проверка | Что ломает |
|---|---|
| `dotnet build -c Release` | не компилируется |
| `dotnet test` | сломалась логика |
| `dotnet format --verify-no-changes` | стиль разъехался |
| `scripts\check-workflow-scripts.ps1` | в пайплайне синтаксис, который не ловит YAML |
| `scripts\check-resource-keys.ps1`, `check-resource-refs.ps1` | ссылка на ресурс не разрешается |
| `scripts\check-release-notes.ps1` | в тексте релиза появились ссылки или сырой markdown |
| сценарии из `scripts/` | сломалась функция |
| эталонные снимки, вручную | изменился внешний вид |
