# 9. Оболочка WPF удалена из решения

- Статус: принято
- Дата: 2026-11-09
- Связано с: [0001](0001-ui-engine-avalonia.md), [0004](0004-avalonia-may-look-different.md)

## Контекст

Перенос интерфейса, начатый в [0001](0001-ui-engine-avalonia.md), завершён: все экраны
собраны на Avalonia, каждый принят, выпуск 2.0.0 готовится из `integration/2.0`.

В решении оставался проект `PhotoBook.Desktop.Wpf`: он не собирался в продукт, но был
второй оболочкой с собственной разметкой, конвертерами, диалогами и точкой сборки.
Держать его дальше означало:

- сотни файлов, которые попадают в поиск и сбивают навигацию;
- два места, где живёт одна и та же логика представления, без признака, какое из них
  настоящее;
- документацию, обязанную описывать обе оболочки, чтобы не врать.

## Решение

Проект `src\PhotoBook.Desktop.Wpf` удалён полностью: представления, конвертеры, диалоги,
ресурсы и запись в решении.

Что перенесено, а не удалено:

| Что | Куда |
|---|---|
| `icon.ico` | `src\PhotoBook.Desktop.Avalonia\icon.ico`; на него смотрит `ApplicationIcon` и установщик |
| `LICENSE-Inter.txt` | `src\PhotoBook.Desktop.Avalonia\Assets\LICENSE-Inter.txt` |
| общие модели представления | `src\PhotoBook.Presentation` (существовали до удаления и ссылок на WPF не имели) |
| скрипты проверки | ищут сборку через `Get-AppExe` в `scripts\common.ps1` и не знают имени проекта |

## Что проверено перед удалением

| Проверка | Результат |
|---|---|
| Ссылки на проект в решении, проектах, скриптах и пайплайнах | нет |
| `dotnet build -c Release` | 0 ошибок |
| `dotnet test` | 125 из 125 |
| `dotnet format --verify-no-changes` | чисто |
| `check-resource-keys.ps1`, `check-resource-refs.ps1` | проходят |
| `audit-closed-steps.ps1` | 22 из 22 |
| Запуск собранной программы | окно появляется, проекты открываются |

## Последствия

- В репозитории одна оболочка и один набор представлений; `Presentation` не требует
  оконного движка, и это проверяется компилятором.
- Проверки закрытых шагов переведены на пути Avalonia: до этого они обращались к
  каталогам удалённого проекта и не проверяли ничего.
- Возврат к WPF невозможен без восстановления проекта из истории; это осознанно.
- Внешний вид 2.0 описан в заметках релиза по [0004](0004-avalonia-may-look-different.md).
