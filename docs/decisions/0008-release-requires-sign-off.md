# 8. Релиз требует подтверждения

- Статус: принято
- Дата: 2026-10-13

## Контекст

`master` защищён, и выпуск идёт только через pull request и ручное подтверждение. До этого
момента правило существовало как практика, а не как записанное решение, а такие вещи теряются
при смене человека за клавиатурой.

Волны 1 и 2 закрыты. Впереди волна 3 — переезд оболочки на Avalonia, — и после неё сборка
должна быть готова к выпуску 2.0.0 как обновление для клиентов, у которых стоит 1.1.1.

## Решение

1. **Релиз выполняется только после явного подтверждения.** Ни при каких обстоятельствах не
   создаётся pull request в `master` сам по себе, даже если все проверки зелёные и волна 3
   закончена.
2. Перед выпуском предъявляется **одно сообщение**: всё готово, вот что проверено, вот что
   осталось. Дальше — пауза до подтверждения.
3. **Только после подтверждения** выполняется финальный pull request в `master` и выпуск.
4. Волна 4 — это уже после выхода 2.0.0 клиентам. В неё входят полноценный раздел
   «Помощь», проработка кнопок темы и контактов, а также решения по механизму обновления и
   лимитам API, которые нужно обсудить.

## Что считается «готово к выпуску»

Не «всё зелёное», а весь список:

| | |
|---|---|
| Сборка | Release, ноль ошибок и ноль предупреждений |
| Тесты | зелёные, покрытие не меньше, чем было |
| Аудит закрытых шагов | `scripts\audit-closed-steps.ps1` — все проверки проходят |
| Проверки ресурсов | оба скрипта проходят, стоят в CI |
| Формат | `dotnet format --verify-no-changes` |
| Приёмка волны 3 | каждый экран принят, видимые отличия согласованы (ADR 0004) |
| Сценарии | `scripts\` зелёные на новой сборке |
| Снимки | сняты, разница объяснена, а не списана на «полосу допуска» |
| Данные пользователя | `%LOCALAPPDATA%\PhotoBookRenamer` не пострадали |
| Заметки к выпуску | без ссылок, на языке пользователя (ADR 0006) |

Всё это перечисляется в сообщении, которое предъявляется до просьбы о подтверждении.

## Последствия

- Ответственность за выпуск остаётся у того, кто подтверждает. Работа доводится до готовности
  и о готовности говорится прямо.
- «Всё зелёное» не является достаточным основанием: CI проходил зелёным при непроверенных
  предположениях (см. ADR 0003 и примечание к шагу 1.3 в истории плана).
- Волна 3 идёт **по экранам**, а не «сначала всё, потом всё»: после каждого экрана — приёмка и
  подтверждение.

## Связанное требование

Всё, что попадает в репозиторий, пишется от лица проекта. В отслеживаемых файлах нет
упоминаний инструментов и участников работы — ни в тексте, ни в именах файлов, ни в истории
коммитов. Служебные заметки ведутся вне репозитория.
