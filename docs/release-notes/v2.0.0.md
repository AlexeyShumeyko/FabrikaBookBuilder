## Fabrika BookBuilder Studio 2.0.0

Новый движок интерфейса и ускоренная работа на больших тиражах. Проекты, имена файлов при
выгрузке и папка данных не изменились: обновление ставится поверх текущей версии.

### Что изменилось

**Интерфейс**

- Все экраны собраны заново на современном движке: одинаковые отступы, скругления, тени и
  шрифты на всех окнах, включая диалоги и окно обновления.
- Список загруженных фотографий и список книг прокручиваются плавно и на тираже в пятьдесят
  книг: строятся только те карточки, которые видны на экране.
- Перетаскивание фотографии в разворот, замена снимка в занятой ячейке и обложка книги
  работают одинаково во всех режимах.

**Скорость**

- Список проектов открывается почти в три раза быстрее: 43 карточки появляются за 0,6 с при
  возврате из проекта и за 2,4 с при первом запуске программы, вместе с запуском.
- Комбинированный проект на 50 книг по 20 разворотов открывается за 4,5 с вместо 8,5 с, и
  окно при этом не замирает.
- Уменьшенные копии фотографий стали меньше по размеру и строятся быстрее: 374 снимка — 11 с
  вместо 15–16 с. Повторно они не строятся вовсе: проект открывается с готовыми копиями.
- Карточка в списке проектов больше не читает оригинал фотографии ради маленького превью.

**Надёжность**

- Ошибка в фоновой задаче пишется в журнал и не закрывает программу.
- Кнопка, которой достался не тот объект, больше не приводит к аварийному завершению: такое
  нажатие просто ничего не делает.
- Прокрутка, перетаскивание и замена фотографии проверены на тиражах до 50 книг.

### После обновления

- Проекты, созданные в версиях 1.1.x, открываются без изменений, имена файлов при выгрузке
  остались прежними.
- Первый запуск после обновления один раз строит уменьшенные копии заново — дальше они
  берутся из кэша.
- Установка выполняется поверх текущей версии, права администратора запрашиваются один раз.
- Если что-то пошло не так, пришлите файлы из `%LOCALAPPDATA%\PhotoBookRenamer`: в них журнал
  и проекты.
