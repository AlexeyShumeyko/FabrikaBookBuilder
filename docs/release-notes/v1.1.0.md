## Fabrika BookBuilder Studio 1.1.0

Полностью переработанный интерфейс. Программой можно пользоваться с нуля: она
проводит по шагам, объясняет каждый режим и подсказывает, что нажимать дальше.

### Что изменилось

**Интерфейс**

- Новый дизайн всех экранов: постоянная шапка с названием проекта и режимами, единая
  панель управления, карточки вместо таблиц, согласованные отступы, цвета и шрифты.
- Режим «Уникальные папки» и режим «Комбинированный» переработаны отдельно, у каждого
  своя логика подсказок — не один текст на оба.
- Статус проекта теперь виден прямо на карточке: сколько страниц, в каком состоянии
  проект, каким он был изменён.
- Пустые состояния объясняют следующий шаг, а не сообщают, что «пока нечего
  показывать».
- Все диалоги (экспорт, выбор папок, подтверждения) выглядят как остальная программа,
  а не как системные окна.

**Комбинированный режим**

- «Во все развороты» и «Во все книги» — общие развороты и общие обложки заводятся одним
  действием, это и есть главный выигрыш на больших тиражах.
- Понятная маркировка: зелёный — свободно, синий — занято, бирюзовый — общий для всех
  книг.
- Панель управления не меняет форму при переключении режимов, в ней не появляется и не
  исчезает ни одной кнопки.

**Экспорт**

- Перед выгрузкой проект сохраняется автоматически.
- Каждая выгрузка попадает в свою новую папку: уже существующие папки не перезаписываются.
- Для режима «Уникальные папки» появилась раскладка по подпапкам — по одной на книгу.
- Оригиналы фотографий не изменяются: программа только копирует их с новыми именами.

**Устойчивость**

- Ошибка в фоновой задаче больше не закрывает программу: раньше повреждённый файл или
  занятый диск могли завершить работу целиком. Теперь ошибка пишется в журнал, а
  программа продолжает работать.
- Если фотография не читается, ячейка прямо говорит об этом вместо молчаливого пустого
  места.

**Скорость**

- Список загруженных фотографий перерисовывается по мере необходимости: проект со
  100 фотографиями открывается примерно в 6 раз быстрее, чем в 1.0.4.
- Миниатюры вычисляются один раз и переиспользуются, а не пересчитываются при каждой
  перерисовке.

### После обновления

- Проверки, отчёты и журналы лежат в `%LOCALAPPDATA%\PhotoBookRenamer`. Если что-то
  пойдёт не так, достаточно прислать файлы из этой папки.
- Проекты, созданные в предыдущих версиях, открываются без изменений.
